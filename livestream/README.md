# 大肥鱼抖音直播桥（原型）

本 fork 新增独立直播桥，不修改上游桌宠内核。弹幕 → 有界队列 → 无工具的对话模型 → dsh-pet TTS → 播放页语音/字幕 + 桌宠说话动画。模型不接入 DSH Agent 的文件、终端或工具能力。

## 先跑本地演示

需要 Node.js 22.9+。进入本目录运行 `npm start`，打开终端显示的地址。页面内置大肥鱼预览动画，点击「一键试播」即可生成模拟弹幕并播放。也可点击「启用声音」，再点「开始处理」，输入模拟弹幕。无需安装依赖，不使用 API。模拟语音来自浏览器的系统语音；这不是抖音实播验证。

默认仅监听 127.0.0.1:39210。地址 # 后面是本地口令，页面加载后会从地址栏移除；勿在直播中展示终端口令。只开一个播放页，多个播放页会重复播音。

## 接真实模型和桌宠

1. 安装并启动 dsh-pet，确认角色已显示，先在其设置里配置并测试 TTS。
2. 将 `.env.example` 复制为 `.env`，设置 `LIVE_MODE=live` 和 `LLM_API_KEY`。密钥仅保存在本机，该文件已忽略。
3. 配置 `LLM_BASE_URL`（以兼容 API 的根路径为准）、实际可用的 `LLM_MODEL`，以及 **实际 DSH HTTP 服务地址** `PET_BASE_URL`。3080 仅为示例，官方桌面端端口可能不同。若桌面端不暴露此接口或需要额外鉴权，当前桥接不兼容；可改用已有可访问的 WebUI Host，并设置对应 surface，不能绕过认证。
4. `PET_ID` 必须是已显示宠物的 ID，`PET_SURFACE` 是 `desktop` 或 `web`。重启直播桥，再测试一条弹幕。

真实模式通过上游 `/voice/speak` 获取音频；`/lock` 占用宠物，`/broadcast` 触发气泡与说话动画（speak=false，避免重复播音）。浏览器播完后回执，服务器释放锁并处理下一条。90 秒未收到播放回执将暂停。模型/TTS/桌宠失败会暂停并显示错误，不伪造成功。当前是预制说话动画，不是逐音素口型。

## 接抖音评论

### A. 已有弹幕接收器

将**自己的直播间**接收器事件转换为以下 JSON，POST 到 `http://127.0.0.1:39210/events`：

```json
{"type":"comment","id":"平台消息唯一编号","user":"观众昵称","text":"你好大肥鱼"}
```

Header：`Authorization: Bearer <本地口令>`、`Content-Type: application/json`。接受返回 202 和 `accepted:true`；重复、刷屏冷却和队列满会返回 accepted:false。只接评论，不接礼物/关注事件。此接口不是抖音官方接入，不会根据房间号自动连接平台。

### B. 浏览器可见评论脚本（实验性，尚未在真实直播间验证）

在支持用户脚本的浏览器里安装 `douyin-visible-comments.user.js`，打开 `https://live.douyin.com/你的房间`，由你正常登录。使用脚本菜单「开始转发」，填写在开发者工具中确认的评论行、正文和昵称 CSS 选择器，确认解析样例，填写本地口令。脚本只读取新出现的可见 DOM，不读取 Cookie、不调用隐藏接口。没有固定选择器：页面改版、虚拟列表复用节点或评论不在 DOM 中时可能漏读，需实播验证和适配。初始历史评论不会转发。刷新页面或菜单「停止转发」停止。

脚本默认桥接端口 39210；改 PORT 时也需修改脚本。原生 Safari 不直接运行此用户脚本，Mac 可用支持相应脚本管理器的浏览器。

## OBS

先在普通浏览器打开播放页并启用声音。OBS 可直接采集播放页内置角色与字幕区域（预览 GIF），或另外采集原生桌宠的高质量动画窗口，另添加该浏览器音频；麦克风若会回录扬声器，请避免重复采集。字幕模式按钮隐藏控制台，Esc 返回。它不是完整 OBS 场景包，也不替你开播/获取推流权限。正式推流前本地录制检查画面、声音和停止按钮。暂不提供自动发文字弹幕。

## 当前边界

- 自动处理模式，不是内容审核系统；公开播出前应有人值守，控制台可停止并清空。
- 每人 3 秒冷却、最多排队 20 条、60 秒过期，避免堆积过时回复。
- 只保留内存中的最近 10 条回答，无磁盘聊天记录；弹幕文字会发送给所配置的模型服务。
- 尚未实测你的直播间、DSH 版本、TTS 音色、OBS 音频路由。
- 当前版本不包含平台登录、验证码处理、礼物感谢、长记忆或直播推流。

验证：`npm test`。上游插件安装方式仍见根目录 README；本 fork 的直播桥需单独启动，安装 npm 原版 `dsh-pet` 不会自动安装本目录。
